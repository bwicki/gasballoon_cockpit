CORS-Test für METAR-/Wetterquellen

Testet direkt aus DEINEM Browser heraus, ob diese APIs per fetch() erreichbar sind (also ob eine Web-App wie GBLP sie direkt nutzen könnte, ohne Umweg über einen Server). Das ist der einzige zuverlässige Test - Analysen von aussen (z.B. robots.txt-Prüfungen) sagen nichts darüber aus.

Wichtig: Öffne diese Datei direkt im Browser (Doppelklick oder "Datei öffnen"), nicht über einen lokalen Dev-Server - für einen echten CORS-Test muss die Seite von einer "fremden" Origin aus laufen, genau wie GBLP selbst.

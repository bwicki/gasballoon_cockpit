Testet direkt aus DEINEM Browser heraus, ob diese APIs per fetch() erreichbar sind (also ob eine Web-App wie Gasballoon Cockpit sie direkt nutzen könnte, ohne Umweg über einen Server). Das ist der einzige zuverlässige Test - Analysen von aussen (z.B. robots.txt-Prüfungen) sagen nichts darüber aus.

Bitte so testen: Lade diese Datei zusammen mit index.html auf denselben GitHub-Pages-Server hoch und öffne sie von dort aus (z.B. https://DEINBENUTZERNAME.github.io/DEINREPO/cors_test.html). Nur dann ist das Ergebnis aussagekräftig.
